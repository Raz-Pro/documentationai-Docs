## Upgrading to the Latest Version

Follow these steps to upgrade RazPro safely.

<Steps>
  <Step title="Backup Data" icon="database">
    Export your current data using the dashboard export tool.
  </Step>
  <Step title="Update Client" icon="download">
    Install the latest version based on your platform.
    <CodeGroup tabs="npm,Docker">
      ````bash
      npm update razpro-client --save
      ````
      ````bash
      docker pull razpro/business-solutions:latest
      docker-compose up -d
      ````
    </CodeGroup>
  </Step>
  <Step title="Run Migrations" icon="settings">
    Execute database migrations.
    ````bash
    razpro migrate --env production
    ````
  </Step>
  <Step title="Verify Integration" icon="check-circle">
    Test QuickBooks sync and profit reports.
  </Step>
</Steps>

<Callout kind="tip">
  For breaking changes in v2.0.0, review the migration guide in your account settings.
</Callout>
