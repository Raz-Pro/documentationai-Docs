## Overview

Follow these steps to start organizing documentation in RazPro.

<Steps>
  <Step title="Navigate to Projects">
    Log in and select the "Projects" tab from the dashboard menu.
  </Step>
  <Step title="Create a new project">
    Click on "New Project", then enter your project name and description.
  </Step>
  <Step title="Save and start organizing">
    Click "Create". You can now add notes, upload files, and invite team members.
  </Step>
</Steps>
